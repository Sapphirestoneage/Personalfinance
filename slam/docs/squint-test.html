Squint test: can a friend tell where they are?

Six screens of SLAM, chosen at random (at least two from the deep levels, where the real work happens), blurred so the words cannot be read closely. Made on 2026-10-28 with seed 10045 (run node tools/squint-kit.mjs --seed 10045 to get the same six). The made-up demo household.

How to run it (two minutes a person)

  1. Print this page (or hand over the screen) and give a friend a pen.
  2. On each screen, ask them to circle six things: the site ID, the page name, the main sections, the options at this level, where "you are here" is marked, and search.
  3. Two minutes for all six screens. No zooming in, no reading closely: a squint is the point.
  4. Count the circles that landed. The answer key on the last page says what is where. Anything missed on two screens or more is a fail for the Phase 3 gate (BOARD.md).
