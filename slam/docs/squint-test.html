Squint test: can a stranger find their way?

Six SLAM screens, picked at random (at least two deep inside), blurred so the words cannot be read closely. Every number on them is made up.

  1. Print this page, or show it on a screen.
  2. Give a friend two minutes. On each screen, ask them to circle and label: site ID (the name of the site), page name, sections (the main tabs), local options (the choices on this page), you are here (which tab is chosen), and search.
  3. Anything they cannot find, or circle in the wrong place, is a fix. Note it on BOARD.md.

Made by tools/squint-kit.mjs; run it again for six new screens.
