New client

A client's numbers stay in this browser, apart from yours. They leave only in a sealed file you make.

Import from a sheet

Export the client's Google Sheet tab as CSV and choose it here. Map each column to a Ledger row once; the mapping is kept by name, so the next client takes seconds. The last filled line of each column is read. A column left unmapped becomes a private note on the client, never a number.

Back up and restore

Every file here is sealed with a passphrase (AES-256-GCM). There is no recovery: a forgotten passphrase means nobody can open the file. Keep these files off shared drives and out of any code repository.
