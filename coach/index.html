Welcome

Three steps, every time

  1. Add a client. A name is enough. Their numbers stay in this browser, apart from anyone else's.
  2. Open a session. Go stop by stop down the path. Type what the client tells you; the pictures update as you go.
  3. Show them their view. One screen for the client: the life map, the goals, what changed, homework.
Try it with the example client

Nothing leaves this device unless you save a locked file on purpose. There is no account and no server.

Empty is not zero. A box left blank means "not known yet". Every box has a ? that says what it means, where to find it, and what to do if unsure.

Add a client

The full path is nine stops, for a new client. The check-up is four, for someone coming back.

Bring a client over from a spreadsheet (optional)
  1. In Google Sheets, open the client's tab and choose File, Download, Comma Separated Values (.csv).
  2. Choose that file here and press Read the file.
  3. For each column, pick where it goes. A column you leave as "Keep as a note" is saved as a private note, never as a number.
  4. Give the mapping a name, so the next client takes seconds.

Keep a safe copy (back up and restore)

A copy is one file, locked with a password you choose. Nobody can open it without the password, not even this app, so keep the password somewhere safe. Keep the files off shared drives.
