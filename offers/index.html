The offer work from Alex Hormozi's $100M Offers, laid out as six planets: Crowd, Price, Value, Offer, Enhancers, Name. Each has four bands, and a band means the same depth on every planet: sketch it, build it, sharpen it, prove it. Finish a band on all six and a ring lights. Everything you type stays in this browser.
