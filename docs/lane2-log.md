# Lane 2 log

One short paragraph per section, newest at the bottom. The lane rules are in the second-lane prompt; the decisions are the L-series in DECISIONS.md.

## Section 1: synthetic household corpus (L-1)

Thirty fixtures under `fixtures/households/` (24 archetypes, 6 edge cases), each generated through `Schema.createHousehold` by `tests/tools/build-households.js` so the shape is the live spine v2 one, with `meta.known` hand arithmetic and its working. `tests/corpus.test.js` sweeps 226 household-first engine functions across 62 engines for throws, NaN and forbidden negatives, and compares ten known values per fixture within 1%: 7109 checks, zero disagreements, one arg-map mistake of my own fixed on the way (statement.portfolios takes access rules, not debt rules). `docs/lane2-findings.md` is regenerated each run and is empty of disagreements; it does list twelve functions the sweep cannot call without a skill, goal or offer, which section 2 will feed. No CI exists in the repo, so "runs in CI" is a workflow proposal in `docs/lane2-proposals.md`. DECIDE: the expected `sphere` on each fixture is a guess until spheres.json lands; and whether known-value disagreements should fail CI (they currently only write to the findings file unless `CORPUS_STRICT=1`).

## Section 2: property tests on every engine (L-2)

`tests/properties/` has one file per engine (64) plus two for the shared modules the invariants name (`levers`, `blocks`), all on fast-check with a fixed seed and 100 cases per property; `run.js` runs the lot in about 15 seconds, well inside the two-minute budget, writes `tests/reports/properties.json` and re-renders the findings file. Every engine gets four generic properties (no throw or NaN, same answer twice, input untouched, whole cents), and 22 files add the listed invariants: savings never above take-home, take-home never above gross, FI target and FI date monotone in spending and income, runway blind to property and monotone in cash, avalanche never dearer than snowball, a level payment repaying its principal, shocks never helping, blocks additive, a lever leaving its input byte-identical. Six properties fail and are logged with shrunk specs: fractional cents in `Tier0.debtToIncome`, `ratios.all` and `skills.available`; a level payment on a tiny principal rounding to negative interest; block application minting a random id on a household with no income source; and the job-loss shock in Long Way Round borrowing less than the shortfall in its year. Three invariants have nothing to hold yet and are recorded as notes: after-tax asset values (section 15), rounding by confidence (section 15), and sequence of returns (no engine takes a return path). DECIDE: as in section 1, failing properties write to the findings file and do not fail the run unless `CORPUS_STRICT=1`.

## Section 3: sourced data tables (L-3)

Eight files under `data/`, every cell an object with `value`, `asOf`, `source` (a URL) and `confidence`, generated by `tests/tools/build-data-tables.js` from compact hand-kept tables so a refresh is one edit and one run: `states.json` grew seven columns for all fifty states and DC (income tax type and top rate pointing at the one bracket schedule, property tax rate, infant care price, auto insurance, cost of living index, UI weekly maximum and weeks, ACA benchmark for a 40-year-old); `milestones.json`, `aca.json`, `studentloans.json`, `contribution_limits.json` and `tax_brackets.json` are new; `return_bands.json` gained its series and window with the values untouched; `bands.json` gained chapter-level citations and a `slafProposed` block (the trench copy the lane asked for, beside Eli\'s live defaults because test/run.js pins one of them). `tests/data.test.js` runs 3957 checks (source and date on every cell, the 18-month rule, every state and column, monotonic brackets, FPL rising with size) and lists every place a new table disagrees with the copy an engine reads: the 415(c) limit, the 2026 top ACA percentage, 27 UI maxima, Ohio\'s flat tax, and one head-of-household bracket it caught in my own table. `docs/data-refresh-calendar.md` says which month each file is re-checked and against what. The honest limit: this session could search the web but not open a page, so most cells are `recalled` with `verify: true`; the sourced ones are the 2026 federal figures a search result quoted. DECIDE: prior-year rows are exempt from the 18-month rule as `historical`, the childcare column is marked `stale` (2023 edition), and the engines still read their old copies (P-3).
